# Torre-de-Hanoi - Abraham-Medina
Métodos:
1.- La función "torre_de_hanoi(n, origen, destino, auxiliar)" es donde se encuentra la recursividad del algoritmo. Su propósito es trasladar los discos entre las tres torres mediante la división del problema en tareas más simples, repitiendo este proceso hasta que solo resta mover un disco, que constituye el caso base.

2.- "main()" es el punto de entrada del programa. Se encarga de recibir la cantidad de discos del usuario, ejecutar el programa y medir el tiempo total transcurrido durante el proceso.

Conclusión:
Programar la Torre de Hanoi en Python es una gran manera de ver la recursividad. Este método permite resolver el problema mediante la repetición simplificada de una misma lógica, evitando el uso de ciclos dificiles o códigos bastante largos.
